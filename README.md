## 👋 About Me

Hey, I'm **Sumonta Dash**, a full stack developer from Bangladesh 🇧🇩 building web and mobile products for clients in **Bangladesh** and **Australia** 🇦🇺.

I like turning messy business problems into software that is fast, secure, and easy to maintain.

- 🔭 **Building:** payroll software for Australian businesses, multi-company POS/ERP systems, payment gateway dashboards, and an offline-first personal finance app
- 🧩 **Side projects:** Chrome extensions
- ⚡ **Daily drivers:** Laravel, Next.js, Node.js, MongoDB, React Native
- 🌱 **Always learning:** new tools, cleaner architecture, better performance
- 🗣️ **Languages:** বাংলা, English
- 💬 **Ask me about:** Laravel, Next.js, REST APIs, database design, payroll/fintech logic
